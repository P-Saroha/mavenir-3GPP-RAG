PRODUCTION OPTIMIZATIONS
═════════════════════════════════════════════════

✓ Dense-only retrieval: Simpler, faster, higher precision than BM25+RRF
✓ Cross-encoder reranking: Joint (query, passage) scoring after retrieval
✓ MMR diversity: Ensures complementary evidence, not redundant chunks
✓ Quality gate: Evidence-grounded abstention (fails closed, not optimistic)
✓ Citation validation: Deterministic ID verification, no hallucinated sources
✓ Single LLM provider: xAI Grok (clear error if unavailable, no silent fallback)
